# Complete run archive

The Git repository contains paper sources, analysis code, generated tables,
selected audit records, masked coding artifacts, and cryptographic manifests.
It intentionally excludes complete run directories and raw request traces.

## Planned archival deposit

- Host: Zenodo, with a GitHub release artifact as a fallback
- Contents: complete immutable run archive, raw requests and trajectories,
  grader outputs, state directories, recovery receipts, and archive-level
  checksums
- DOI: **pending**
- Release gate: secret and PII scan of the archive, independent verification
  of archive checksums, then DOI insertion into the paper and citation metadata

No DOI has been invented for this draft. The arXiv source and PDF must retain
the explicit “DOI pending” marker until the deposit exists.
